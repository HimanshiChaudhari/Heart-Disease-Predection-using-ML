Developed an end-to-end supervised machine learning classification pipeline on 1,000+ patient records. Performed data cleaning, missing-value imputation, categorical encoding, feature scaling, EDA, feature analysis, and outlier detection. Implemented and compared Logistic Regression, KNN, Decision Tree, and SVM models using accuracy, confusion matrix, precision, recall, and F1-score. Built a frontend–backend ML application to serve predictions from the trained model.
